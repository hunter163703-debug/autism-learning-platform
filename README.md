# 自閉症與溝通障礙 多元教學互動與核心概念檢測平台

> 🎓 **教學平台製作**：亞洲大學 聽力暨語言治療學系 語言組 · 林樺鋒老師 製作

本專案為專門針對「自閉症與溝通障礙」臨床與特教專業課程打造的雲端互動教學與評量平台。結合現代響應式網頁設計（RWD）、Cloudflare Workers 全球邊緣運算、Cloudflare D1 雲端關聯式資料庫，以及導入 **AI 蘇格拉底引導詰問家教（Socratic Method）**，完整追蹤全學期多章節學習歷程與核心盲點突破。

---

## 🌟 核心特色

1. **臨床核心概念檢測（支援多章節架構）**：
   - 第一節：自閉症診斷與臨床表現（DSM-IV 至 DSM-5 診斷演進、流行病學、致病成因、神經生理機轉與行為特徵）。
   - 架構具高度擴充性，支援學期後續第二節、第三節持續擴充與長期歷程比對。
   - 每題均附帶選項 A/B/C/D 逐項詳細剖析與核心觀念歸納。

2. **AI 蘇格拉底盲點引導家教（Socratic AI Tutor）**：
   - 採用啟發式提問法，不直接公佈答案，引導學生梳理思路盲點。
   - **題目與選項即時看板**：引導對話時全程展示題幹與四個選項，清楚標示「👉 您的選擇」與「✅ 標準解答」，防止學生遺忘。
   - **觀念突破辨識**：當學生於對話中成功釐清關鍵概念時，AI 自動給予肯定並標記 `clarified` 破障成功。

3. **Cloudflare D1 雲端分散式資料庫整合**：
   - 自動保存學生學號、姓名、作答時間、測驗成績、詳細錯題清單。
   - 完整記錄每一位學生與 AI 蘇格拉底家教的對話輪數、突破狀態與逐字稿歷程。

4. **全方位師生共覽儀表板 & 5 工作表專業 Excel 報表**：
   - 學生總表、錯題深度剖析、全班難點與教學鑑別、AI 家教破障總覽、AI 逐字對話歷程。
   - 支援線上一鍵投影全班全卷檢視，便於課堂即時研討。

5. **極致響應式體驗（RWD）**：
   - 完美適配 iPad、平板電腦、智慧型手機與電腦桌機，支援觸控操作與邊緣抽屜手勢。

---

## 🛠️ 技術架構

- **前端技術**：HTML5, Tailwind CSS, FontAwesome 6, 原生高效 JavaScript (ES2022)
- **邊緣雲端運算**：Cloudflare Workers
- **雲端資料庫**：Cloudflare D1 (`autism-comm-disorders-db`)
- **AI 語言模型**：Groq API (Qwen 3.8 / Llama 3 系列高效推論引擎)
- **報表匯出引擎**：Python OpenPyXL (客製化配色與樣式多工作表 Excel 報表)
